# Estructura del Contenido

## Descripción de la sección

Organiza el contenido del videojuego en unidades manejables: mundos, capítulos, zonas, niveles, misiones y desafíos.

## Estructura

```text
Juego
├── Mundo / Capítulo 1
│   ├── Nivel
│   ├── Nivel
│   └── Jefe / Evento
├── Mundo / Capítulo 2
│   └── ...
└── Final
```

## Cantidad estimada

| Tipo | Cantidad |
|---|---:|
| Mundos | 1 (la torre) |
| Niveles | 4 a 5 pisos |
| Misiones | |
| Enemigos | 6-8 tipos incluyendo variantes (en diseño) |
| Jefes | 1 (Dante, jefe final) |
| NPC | |
| Objetos | |

## Dependencias

La demo tiene 4 a 5 pisos; el último contiene al jefe final.
